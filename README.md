# 沙漠土壤微生物组研究数据

## 项目简介

内蒙古基地沙漠土壤化生态恢复项目的微生物组研究数据，涵盖 **16S rRNA 细菌** 和 **ITS 真菌** 扩增子测序分析。

- **研究对象**：沙漠土壤化生态恢复样地（狼尾草 / 高粱种植）
- **样本范围**：A0–A21
- **分析内容**：Alpha/Beta 多样性、物种组成、LEfSe、相关性分析、CPCoA、Venn 图、进化树等

## 目录结构

| 目录 | 内容 |
|---|---|
| `alpha/` | Alpha 多样性分析 |
| `16Sbeta/` `ITSbeta/` `Beta多样性PCoA分析/` | Beta 多样性 / PCoA |
| `tax/` `注释表/` | 物种注释与分类表 |
| `lefse/` `lefse分析/` | LEfSe 差异分析 |
| `柱状堆叠图/` `冲击图/` `Venn图/` `聚类图/` `进化树图/` | 各类可视化图表 |
| `细菌A0-A21/` `真菌A1-A21/` | 分样本数据 |
| `数据处理代码/` `script/` | 分析脚本（R / Shell） |
| `沙漠数据整理/` | 数据整理中间文件 |
| `database/` | **参考数据库（未上传，见下方说明）** |

## 参考数据库（需自行下载）

由于 GitHub 单文件限制 100MB，`database/` 目录未包含在本仓库中。分析时需自行下载以下数据库并放入 `database/` 目录：

| 数据库 | 用途 | 下载来源 |
|---|---|---|
| SILVA 16S v123 | 16S rRNA 细菌分类注释 | https://www.arb-silva.de/ |
| UNITE ITS | ITS 真菌分类注释 | https://unite.ut.ee/ |

## 顶层数据文件

- `metadata.txt` / `metadata.xlsx`：样本元数据
- `16S.otutab.*` / `ITS.otutab.*`：OTU/ASV 丰度表
- `16S.sum_*.txt` / `ITS.sum_*.txt`：门/属水平汇总表
- `*.R` / `*.sh`：分析脚本
- `沙漠.pptx`：项目汇报 PPT
- `沙漠_土壤化_生态恢复理论与实践.pdf`：参考文档

## 数据说明

本仓库包含原始分析数据、中间结果、可视化图表和分析脚本，可复现完整分析流程。
